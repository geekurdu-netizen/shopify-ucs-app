# UniLink Courier Solutions (UCS) - Shopify App

This app connects your Shopify store to the **UniLink Courier Solutions (UCS)** portal. It allows you to view recent orders directly from your Shopify dashboard and book them with UCS. Once an order is booked, the app automatically creates a fulfillment in Shopify with the UCS tracking number.

## Features
- Seamless connection to the UCS API using your API Key.
- View recent 10 orders and their payment/fulfillment status.
- One-click booking to UCS.
- Automatic fulfillment creation in Shopify.
- Integrated with Shopify App Bridge v4 and Polaris.
